# SavvySheet

En modern webbapp för att ladda upp, redigera och exportera Excel och Google Sheets – allt direkt i webbläsaren!

[💻 Preview](https://virtual-dominators.github.io/SavvySheet/)

## Skapare

- [EmelieVilor](https://github.com/EmelieVilor)
- [MohYab](https://github.com/MohYab)
- [ThelmaMattsson](https://github.com/ThelmaMattsson)
- [tombenrex](https://github.com/tombenrex)

## Funktioner

- Ladda upp och visa Excel/Google Sheets
- Redigera data direkt i tabell
- Exportera till Excel, PDF och Google Sheets

## Installation

```bash
npm install
npm run dev
```
